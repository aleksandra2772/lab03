# Лабораторная работа №3

Анализ и моделирование данных предметной области

Цель работы:

Изучить принципы анализа предметной области и моделирования данных.

Предметная область:

Сервис аренды автомобилей

Краткое описание:

В ходе работы были выделены основные объекты предметной области сервиса аренды автомобилей, определены их атрибуты и связи, выполнена классификация данных и построена концептуальная модель.
